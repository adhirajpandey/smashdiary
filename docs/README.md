# Documentation

This directory is organized by intent so contributors can find the right level of detail quickly.

## Structure

### Architecture

- [architecture/overview.md](./architecture/overview.md): application structure, runtime modes, and read/write flow
- [architecture/data-model.md](./architecture/data-model.md): schema, relationships, resolved data shapes, and migration expectations

### Guides

- [guides/development.md](./guides/development.md): local setup, runtime modes, commands, testing, and contributor workflow

### Product

- [product/walkthrough.md](./product/walkthrough.md): implemented screens, workflows, and current product boundaries
- [product/stats-and-leaderboard.md](./product/stats-and-leaderboard.md): detailed stats, rating, leaderboard, and format-segmentation behavior

### Design

- [design/system.md](./design/system.md): visual system and UI design guidance
- [design/references/](./design/references/): screenshots and visual references

## Reading Order

If you are new to the repo, start here:

1. `../README.md`
2. [guides/development.md](./guides/development.md)
3. [architecture/overview.md](./architecture/overview.md)
4. [architecture/data-model.md](./architecture/data-model.md)

If you are changing UI, also read [design/system.md](./design/system.md).
